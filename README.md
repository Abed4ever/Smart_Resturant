# Smart_Resturant
Manage your restaurant tables, control orders, reserve tables, monitor the kitchen, make a menu available via QR Code to your customers
- Installation
-   download xamp or wamp with php8.2
-   download project into www in wamp , in xampp add project files into httdoc
-   in phpmyadmin create database with name "resturants2025" import resturants2025.sql
-   in phpmyadmin create user with (user name : sms2 , password :123456)
-   open new browser window to goto system url http://127.0.0.1/ab_resturant_2025/app_Login/
